# quarto-dl-site
Dedicated repository containing all materials, models, and notebooks for hosting a Quarto portfolio site to aggregate deep learning model projects. Contains classification models ported from the **fastai-course** repository, and will also contain any future deep learning projects. To visit the site live, [click here](https://pontiacgto2006.github.io/quarto-dl-site/). 

The Ashryver model, CIFAR model, and QuickDraw models have now been added, and I'm in the process of rolling out a new, more flexible UI design for all three of these models.

# Structure and contents
Primarily contains the models and notebooks necessary to host blogs and live demos. Also included are JavaScript controller files for the custom UI logic and sets of example images for usage in the demo. As I continue to work on new deep learning AI projects in the main **fastai-course** repository, those models may be ported here to be put on display.
